# 🎬 GUION PRO 2.0

## Sistema Profesional de Escritura de Guiones para Google Docs
### ✨ Con Soporte Completo de Fountain

---

## 🚀 ¿Qué es Guion Pro?

**Guion Pro** es un sistema completo de escritura de guiones cinematográficos que funciona enteramente dentro de Google Docs usando Apps Script. 

### Características Principales

✅ **Parser Fountain Completo** - Convierte sintaxis Fountain a guion formateado con un clic  
✅ **Formateo Inteligente** - Detecta automáticamente el tipo de bloque  
✅ **Panel Lateral Interactivo** - Acceso rápido a todas las funciones  
✅ **Navegación de Escenas** - Índice clicable de todas las escenas  
✅ **Autocompletado** - Reutiliza personajes y localizaciones  
✅ **Exportación Bidireccional** - Fountain ⇄ Guion formateado  
✅ **100% Gratis** - Sin servidores externos, sin suscripciones  
✅ **Colaboración en Tiempo Real** - Powered by Google Docs

## 📖 Inicio Rápido

### Modo 1: Fountain → Guion (Recomendado)

1. **Escribe tu guion en texto plano** usando sintaxis Fountain:
   ```
   INT. CAFETERÍA - DÍA
   
   Juan entra apresurado.
   
   JUAN
   ¡Llegué a tiempo!
   
   MARÍA
   El jefe te espera.
   
   CORTE A:
   ```

2. **Formatea todo de golpe:**
   - Menú: `🎬 Guion` → `✨ Formatear Todo (Fountain → Guion)`
   - O Panel Lateral: `✨ Formatear Todo el Documento`

3. **¡Listo!** Tu guion está formateado profesionalmente.

### Modo 2: Formateo Bloque por Bloque

1. Escribe un párrafo
2. Click en el tipo de bloque en el panel lateral
3. O usa `🎬 Formateo Inteligente (Bloque)` para detección automática

## 🎯 Sintaxis Fountain (Resumen)

| Elemento | Sintaxis | Ejemplo |
|----------|----------|---------|
| **Escena** | `INT.` / `EXT.` | `INT. CASA - DÍA` |
| **Personaje** | MAYÚSCULAS | `JUAN` |
| **Diálogo** | Texto después de personaje | `Hola, ¿cómo estás?` |
| **Parentético** | Entre paréntesis | `(sonriendo)` |
| **Acción** | Texto normal | `Juan camina hacia la ventana.` |
| **Transición** | Termina en `TO:` | `CORTE A:` |

Ver [Fountain.io](https://fountain.io) para la especificación completa.

## 🛠️ Funcionalidades

### Menú "🎬 Guion"

- **Insertar Bloque** - Inserta elementos con formato
- **Convertir a...** - Cambia el tipo de un bloque existente
- **✨ Formatear Todo (Fountain → Guion)** - Convierte todo el documento
- **📌 Formatear Selección (Fountain)** - Convierte solo la selección
- **🎬 Formateo Inteligente (Bloque)** - Detecta y formatea automáticamente
- **🔢 Renumerar Escenas** - Numera todas las escenas (1), (2), (3)...
- **🧹 Limpiar Formato** - Elimina formato inconsistente
- **📤 Exportar** - A Fountain, PDF, o nuevo documento
- **📊 Ver Estadísticas** - Análisis del guion
- **🧭 Índice de Escenas** - Lista de todas las escenas
- **📱 Abrir Panel Lateral** - Panel interactivo
- **⚙️ Configurar Documento** - Aplica márgenes y fuente profesionales

### Panel Lateral

- **⚡ Formateo Fountain** - Botones de conversión rápida
- **📦 Tipos de Bloque** - 8 tipos de elementos
- **🛠️ Herramientas** - Formateo inteligente, renumeración, limpieza
- **🧭 Navegación** - Índice clicable de escenas
- **👥 Personajes** - Lista de todos los personajes
- **📍 Localizaciones** - Lista de todas las localizaciones
- **🎭 Plantillas** - INT/EXT DÍA/NOCHE, transiciones

## 📊 Formato Profesional

El sistema aplica automáticamente los estándares de la industria:

- **Márgenes:** 1.5" izq, 1" resto
- **Fuente:** Courier New 12pt
- **Interlineado:** Simple
- **Sangrías:** Según tipo de bloque
  - Personaje: 2.5" desde izquierda
  - Diálogo: 1.5" izq y der
  - Parentético: 1.75" izq

## ⚠️ Limitaciones

### ✅ Lo que SÍ hace:

- ✅ Formateo profesional estándar
- ✅ Parser Fountain completo
- ✅ Navegación rápida
- ✅ Exportación PDF y Fountain
- ✅ Colaboración en tiempo real
- ✅ Control de versiones
- ✅ Gratis, sin suscripciones

### ❌ Lo que NO hace (vs Final Draft):

- ❌ Autocompletado en tiempo real mientras escribes
- ❌ Cálculo de páginas con precisión absoluta
- ❌ Production breakdown automático
- ❌ Dual dialogue (dos personajes simultáneos)
- ❌ Templates específicos de TV
- ❌ Import/export FDX directo

Ver [LIMITACIONES.md](LIMITACIONES.md) para más detalles.
